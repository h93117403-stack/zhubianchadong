更新说明 D-3.2.8 ← D-3.2.7
本说明仅比较「当前版本 D-3.2.8」与「上一版本 D-3.2.7」的差异，不含更早版本的累积变更。
  • 可选模块页改为「外层固定展开 + 内层模块默认折叠」：整页容器不再折叠，页内各折叠块进入页面时一律处于收起状态，先看到模块清单，需要哪个再展开。
    · 外层容器由 <details> 改为普通容器，标题变为静态标题栏（点击不再折叠）——避免和外层形成两级折叠、点错层级。
    · 模块 A 定值单读取 / B 二次电流角度计算器 / C 由试验值反推 ID/IR / D 表显数值反算：去掉默认 open，展开与否完全由用户点击决定。
    · 「可选模块版本一览」同步改为默认收起（它同样位于本页内），打开即可查看各模块当前版本与沿革。
    · 各模块的输入 id、计算链路、跨模块同步、导出字段均未改动，仅调整容器结构与折叠默认态。
  • 本次改动属页面容器与折叠默认态，未触及任何模块的计算或数据链路，因此按模块版本管理规则，可选模块 A / B / C / D 的模块版本均保持不变（A v1.0 / B v1.0 / C v1.0 / D v1.1）。
  • 本「更新说明」内容随版本更新，仍只保留当前版本与上一版本的差异。
